# Remoção de Stopwords com NLP

Este repositório apresenta um estudo prático sobre a remoção de stopwords (palavras irrelevantes) em textos em português e inglês. A técnica é aplicada com bibliotecas populares de NLP como `nltk` e `spacy`.

## 📘 Descrição

O notebook inclui:

1. **Leitura e tokenização de textos**: Divisão do texto em palavras.
2. **Remoção de stopwords**:
   - Utilização do `nltk` para diferentes idiomas.
   - Uso de `spacy` com modelos de linguagem.
3. **Comparação entre métodos**.
4. **Exemplos práticos com frases e textos reais.**

## 🛠️ Tecnologias e Bibliotecas

- Python 3.x
- nltk
- spacy
